# Security Policy

This repository holds pictures and no code. Report a security problem of Kuutti privately through the app repository's form, as its [security policy](https://github.com/kuutti-ry/kuutti-app/blob/main/SECURITY.md) says: https://github.com/kuutti-ry/kuutti-app/security/advisories/new

If a picture here looks like you, write to hello@kuutti.app (README, Removal requests).
